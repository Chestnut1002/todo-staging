# 开发需求文档

## 项目概述
Windows 桌面待办事项（Todo）应用，帮助用户记录和管理目标任务。

## 核心功能需求

### 1. 任务管理
- 用户可以添加新的待办任务
- 每个任务前有一个可点击的圆圈按钮
- 点击圆圈表示完成任务，触发渐隐动画后自动删除
- 已完成任务同样可以通过点击圆圈删除

### 2. 时间分类
- 任务可以归属到**具体日期**（如 2026-06-09）
- 任务可以归属到**周期**：
  - 「本周」— 不指定具体日期，属于当前周
  - 「本月」— 不指定具体日期，属于当前月
- 支持日视图、周视图、月视图三种浏览模式

### 3. 日历浏览
- 左侧显示月历小部件（月历网格）
- 支持左右箭头切换月份
- 今天的日期高亮显示
- 有任务的日期下方显示小圆点标记
- 点击任意日期可查看/添加该日任务
- 可点击周号切换到对应周视图

### 4. 搜索功能
- 顶部搜索框，输入即搜（防抖 300ms）
- 支持模糊匹配：输入任务名称中的任意字即可找到
- 搜索结果需显示：任务名称、所属日期/周期、是否已完成
- 高亮匹配的关键字

### 5. 界面设计
- 整体风格：简洁、直观
- 主题颜色：淡蓝色 + 白色为主
- 布局：左侧月历 + 右侧任务列表
- 顶部：搜索栏 + 视图切换按钮
- 底部：状态栏（任务计数）

## 非功能需求
- 运行平台：Windows
- 安装方式：双击 .exe 运行
- 数据本地存储，离线可用
- 界面响应流畅，动画丝滑
